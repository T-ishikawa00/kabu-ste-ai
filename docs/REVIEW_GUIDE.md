# 安全なレビューと再現性に関する現状

## レビュー時にできること

- コード・設計・設定の**静的な確認**。
- Gitのコミット履歴とファイル構成の調査。
- モデルやログの存在と形式の確認。ただし、認証・個人情報を含む可能性があるデータの内容は外部へ開示しない。

## 現在提供できないもの

- 再現性が確認された依存関係のセットアップ手順。
- 外部APIから完全に隔離された動作デモ。
- 安全性が検証されたダミー口座・模擬注文環境。
- 同一条件で再現可能な学習・バックテスト結果の保証。

## コードから確認できる主な技術要素

Python、NumPy、pandas、pandas-ta、PyYAML、requests、Gymnasium、Stable-Baselines3、PyTorch等の利用を確認できます。これは**ソース内のimportに基づく一覧**であり、正確なバージョン一覧ではありません。

## 起動について

`main.py`、各種 `.bat`、認証スクリプト、売買・緊急決済スクリプトは、外部APIへ接続する可能性があります。**起動せずにコードを確認してください。**

次の段階で、別環境において、ダミーデータとモック注文APIのみを利用するオフライン検証系を設計できます。安全性を確認できるまでは、実行コマンドをREADMEに掲載しません。
